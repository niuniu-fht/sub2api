# 全站组件化改造：Magic UI + Motion Primitives + 本地 shadcn/ui

目标：删除所有手写动画和手写 HTML 样式串，全部换成开源组件组合。零新增 npm 依赖（Magic UI / motion-primitives 是 MIT 协议 copy-in 组件，仅依赖项目已有的 `motion/react` + `cn`）。

## 一、引入开源组件（先读文档/源码，再拷入）

**Magic UI（MIT）→ `components/magicui/`**（源码已调研确认，与本项目 motion@14 + Tailwind v4 兼容）：
- `number-ticker.tsx` — 数字滚动（替换自研 CountUp.tsx，删除该文件）
- `animated-gradient-text.tsx` — 渐变流动文字（大标题 + 状态徽章）
- `shimmer-button.tsx` — 流光主按钮（Hero CTA / 导航控制台按钮）
- `border-beam.tsx` — 边框光束（统计卡片）
- `particles.tsx` — 画布粒子背景（替换两处手写 motion.div 光斑）
- `dot.tsx` — 呼吸状态点（替换手写 animate-ping 双 span）

**motion-primitives（MIT）→ `components/motion-primitives/`**：
- `animated-tabs.tsx` — 滑动胶囊 Tab（一处组件同时替换 site-nav 与平台筛选两处手写 layoutId 胶囊）
- `fade-in.tsx` / `fade-in-stagger.tsx` — 入场动画组件（替换手写 fadeUp/交错变体）

获取方式：实施时用 curl 拉 GitHub raw（已验证 web reader 可用但间歇 500，curl 作主通道）；文件头保留组件库出处注释。globals.css 中按 Magic UI 文档加入其要求的 `@keyframes background-position-animation`（组件库自带 CSS，非手写样式）。

**本地 shadcn 库补齐 → `components/ui/separator.tsx`**（`@radix-ui/react-separator` 已安装但从未使用）。

## 二、逐文件重写（全部组件组合，不留手写动画）

1. **`app/HomeClient.tsx`**：背景→`Particles`；状态徽章→`AnimatedGradientText`+`Dot`；大标题渐变行→`AnimatedGradientText`；入场→`FadeIn`/`FadeInStagger`；CTA→`ShimmerButton`（主）+`Button asChild`（次）；统计卡→`Card`+`NumberTicker`+`BorderBeam`。
2. **`components/site-nav.tsx`**：导航项→`AnimatedTabs`（内置弹簧胶囊）；控制台→`ShimmerButton`（紧凑尺寸）；页脚链接→`Button ghost asChild`+`Separator`。
3. **`components/plaza/PlazaToolbar.tsx`**：平台筛选芯片→`AnimatedTabs`；其余已是 Radix Select/ToggleGroup/Input/Button，保持。
4. **`components/plaza/ModelCard.tsx`**：容器→`motion.li`（motion 框架布局动画，库的标准 API）包 `Card`；图标→复用共享 `ProviderIcon`（删除本地 ICONS 重复实现）；平台徽章/价格档位→`Badge`；操作按钮→`Button size="icon-sm"` + `Tooltip`；菜单已是 DropdownMenu。
5. **`components/plaza/GroupsBoard.tsx`**：交错入场→`FadeInStagger`/`FadeIn`；空状态→`Card`；分组头平台徽章与计数→`Badge`。
6. **`app/plaza/PlazaClient.tsx`**：光斑→`Particles`；入场→`FadeIn`。
7. **删除** `components/CountUp.tsx`。
